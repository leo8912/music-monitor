# 技术需求规格

> 版本: 1.0.0

## 技术栈规范
1. **核心后端**: Python 3.11+, FastAPI (0.100+)
2. **异步IO**: asyncio, aiohttp (全链路异步抓取)
3. **数据库**: SQLAlchemy 2.0+ (支持基于 asyncio 的 session)
4. **前端UI**: Vue 3 + Vite, Apple Music / Spotify 混合暗黑风
5. **元数据管理**: Mutagen, 兼容 ID3v2 标签标准

## 设计模式与原则
1. **依赖管控**: 涉及外部 HTTP 调用的 Service 应由 `_singletons` 产生被动单例。
2. **命名约束**:
   - 后端 JSON 返回全部采用 `snake_case`；
   - 内部变量需符合 PEP 8。
3. **错误处理**: Service 模块内发生的异常在 router 侧应当有全量拦截的统一异常视图。
